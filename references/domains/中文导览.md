# 领域知识中文导览

这些摘要用于找资料，不是项目业务决定。每个领域保留原来源和有效性提示；中文术语也不决定适用法域。项目特有角色、权限和阈值只放项目基线。

| 领域 | 主要问题 | 常用入口词 |
|---|---|---|
| [交通运输与安全监管](domain-traffic.md) | 围绕运输企业、车辆、驾驶员与监管机构，说明资质、安全检查、风险预警、隐患整改和教育培训怎样形成可追溯的业务闭环。适合监管端与企业端协同；行业指标和地方执行规则仍须按项目核实。 | 交通、道路运输、交通安全、运输监管、运管、交通运输 |
| [客户关系与客户服务](domain-crm.md) | 覆盖线索、客户、商机、合同、回款、服务工单与续约。重点检查对象转化、归属与协作、金额和状态的一致性，避免把签约、开票、回款及收入确认当成同一结果。 | 客户管理、销售管理、CRM、客户关系、销售漏斗 |
| [教育教学与培训](domain-education-it.md) | 覆盖学生与学籍、课程与班级、选课学习、考试成绩、补考及培训档案。重点是身份与学期、学习证据、成绩生效和角色边界；学校及行业政策不能由样例替代。 | 教育、教务、学工、教育信息化、校园、高校 |
| [协同办公与组织流程](domain-oa.md) | 覆盖组织权限、待办审批、公文、会议、任务督办、知识与电子签章。重点是工作对象、责任交接和正式结果，区分通知、审批、发文、签署及归档。 | 办公、协同办公、OA、办公自动化、组织管理、政务办公 |

| [AI 应用与智能体](domain-ai-native.md) | 覆盖智能体任务、上下文检索、工具调用、人工确认、结果交付与评估。重点区分模型建议、工具已执行和业务已成功，保留权限、失败恢复、证据与成本边界。 | AI应用、人工智能、智能体、Agent、大模型应用、AI原生 |
| [内容生产与知识管理](domain-media-knowledge.md) | 覆盖文档、音视频、转写、知识条目、审校发布和引用检索。重点保持内容、版本、权限、来源和时间码关系，区分草稿、已发布与已撤回。 | 媒体、内容管理、知识管理、知识库、视频平台、内容生产 |

## 查找方式

```powershell
python scripts/query_domain.py --list
python scripts/query_domain.py --domain 数据底座 --section 指标口径
python scripts/query_domain.py --search "指标口径修改以后历史结果怎么办" --limit 8
```

先看摘要选领域，再用业务词查正文。结果显示命中词、来源章节与候选出处；领域内的别名扩展避免把同名词跨行业混用。摘要、关键词和排序提高已知表达的可发现性，不能保证所有问法、错别字、新行业和新规则都能命中。未命中时缩短为关键业务词、指定领域阅读原文，必要时查询可靠的外部来源。
