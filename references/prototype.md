# 可操作原型

按任务读取业务规格、存量基线及[团队设计原件](team-customization.md)。指定单 HTML 就交单 HTML；编辑时可分本地 CSS/JS/数据再合成。保留既有布局、密度、组件和代表数据，不从内置样例移植审美。

## 范围与路径

按实际授权交付，缺决定只限制依赖部分。

盘点受影响页面、入口、处理器、对象、身份、状态及Mock边界。大文件先索引再按路径读；机器盘点可用 `scripts/extract_interaction_ledger.py` 或 [Stage 0 模板](templates/stage0-inventory-template.yaml)，轻改简记即可。

先完成一条任务路径再扩页面；核对身份、状态、结果及重开。配置按[配置产生行为](specify.md#接收者冷读与行为验证)验证，预期取自来源。

## 产品与评审

默认可操作产品态。双态按 [review-workspace.md](review-workspace.md)，先业务与就近说明，再组装映射。

两态共用产品页面、状态、动作；评审选择/高亮/展开不得改业务数据。业务审批与需求评审分别建模。主阅读面说业务，稳定 ID、枚举和技术追溯收起。无 UI 的系统规则不伪造按钮；候选不自动成为正式点。辅助评审功能仅启用时承担对应合同。

就近说明可用组件附加，不复制教学业务。正式R0/R1才承担工作台合同，附加说明不冒称正式工作台。单HTML需核对依赖，不把预览壳当单文件。

## 交互约定

按任务排布筛选、动作、列表、详情及编辑；非用户说明放需求或评审层。沿用主次按钮、状态与必填提示，在常用宽度核对换行、宽表与弹层，不把某个产品尺寸变成通用规则。

字段共用定义：输入有维护入口，派生值有来源。依赖选择先选来源，换来源清失效引用、保留有效输入；节点配置消费真实上游字段，以标识而非名称区分。

| 属性 | 机器约定 |
|---|---|
| `data-action` | `ACT-<DOMAIN>-<NAME>`；纯界面用 `UIACT-*`，评审用 `UIACT-REVIEW-*`；后缀仅字母、数字、连字符，禁止下划线 |
| `data-testid` | 页面 `page-VIEW-*`，浮层 `modal-MODAL-*` / `drawer-DRAWER-*`，区域 `region-REG-*`；稳定且当前 DOM 唯一 |
| `data-metric` | `METRIC-*` 按业务含义分配；重复展示须同口径和 `data-metric-label` |

每个业务动作须有真实处理器、允许条件、结果和失败反馈。普通导航不强绑业务 AC。JS 模板保留完整字面量 `data-action`，不能删除锚点规避检查；静态候选可枚举不代表运行时可达，须从真实入口打开验证。

各入口共享对象取数、允许条件和状态转换；提交时复核。打开表单后改变关闭、权限或成功编号中的一个条件，再提交须拒绝且无新写入。提醒、处置、回执若属不同维度，不能为省字段合成一个状态。展示名称不是对象标识；当前身份约束全部呈现与操作，包括提示、详情、草稿与未决请求。DOM投影当前状态，不另存业务副本。

- 同一动作的行内、详情、批量等实际入口按相同对象/状态/身份核对守卫与副作用；差异须有业务依据。修改字段后立即点击提交，检查失焦/重绘是否吞掉第一次点击；再关闭重开并读下游，防局部成功被另一缓存覆盖。记录实际写入对象，公开 Mock 边界。
- 字段按已定顺序规范化与校验，控件限制不能截断合法值；失败保留输入。用含引号、换行的合法值保存重开，核对内容不被 HTML/属性拼接改变。必填、格式、依赖、重复、并发及空零按业务验证，状态须可达。
- 优先事件委托和 `data-*` 参数；父处理器排除输入控件，需保留光标时不要整片重建。浮层带当前对象，只由真实业务入口打开。
- 外部 iframe 仅用于真实集成，说明来源/信任边界/失败退路；可打开不等于集成验证。

未决在评审层引用原 UNK 和影响；产品只实现已授权边界，不代定冻结指标、取最新或自动补偿。负责人缺失写未指定。

## 验证与完成

按来源反查角色、页面、状态、数据及视觉，可用 PAGE-CONTRACT；获准删除须同步入口/处理器与依据。

跨模块主链、受守卫状态、多系统数据流分别按需画最小流程/状态/数据图，与正文及运行对象一致；简单 CRUD 不堆图。

从来源清点覆盖，不由 marker 决定。浏览器验证提交、重开及后续读取，入口报错先修；调函数仅算模拟，截图核对正文与遮挡。保持详情/浮层打开后切换身份或对象，再提交；同名不同ID仍独立。异步刷新查询原请求再测旧页，不抹掉历史编号；禁用按钮不证明旧请求被拒。记录动作、预期、前后数据及文件，改后复验，未执行/阻塞不记通过。

```powershell
python scripts/ai_delivery_spec_cli.py gate --profile prototype --prototype review.html --prd PRD.md --stage specify --require-review-workspace --format json --diagnostics full
python scripts/scan_prototype_css.py app.html
```

正式评审带 `--require-review-workspace` 和实际基线。R*表示评审方式，旧L0–L4不决定篇幅或风险。无IA侧车仅表示未查。机器交接见 [context.md](context.md)。

原型内以可展开说明关联需求版本，区分业务、演示数据/身份与评审工具；工具不写成业务需求，新增行为不自动获得批准。
