# 制度列表：仅看当前有效

这是虚构示例。下面的权限和时间规则视为本例已确认事实，不能直接移植到其他项目。

## 目标与范围

员工能在现有制度列表排除失效及尚未生效的制度。不改制度状态、搜索排序和现有权限，不保存个人筛选偏好。本次只涉及一个列表筛选，无外部集成。

## 列表筛选

<!-- ADS:behavior -->

已登录且有列表访问权限的员工，在现有筛选区末尾使用“仅看当前有效”开关。开关默认关闭，退出页面后不保留。

| 操作或条件 | 系统结果 |
|---|---|
| 开启开关 | 显示已启用标签；从第 1 页显示当前有效且有权查看的制度，分页大小不变。 |
| 有效时间判定 | 以查询时服务端时间为准：生效时间已到，且失效时间未到或为空。恰好到生效时间时纳入，恰好到失效时间时排除。 |
| 与其他条件一起使用 | 和已有关键词、分类及组织/制度数据权限取交集。开关不扩大范围，也不改任何制度数据。 |
| 关闭开关 | 移除本条件，保留关键词、分类与分页大小，回到第 1 页。 |
| 没有匹配记录 | 显示“暂无当前有效制度”和清除筛选入口，不作为系统错误。 |
| 查询失败 | 保留开关和其他输入，提示重试；不把旧结果显示成这次查询的最新结果。 |
| 无列表权限 | 隐藏入口；直接访问旧地址或构造筛选请求，服务端仍校验身份与数据权限，拒绝越权请求，不返回制度记录。 |

## 验收

以下验收使用固定服务端时刻 2026-10-28 10:00；其余筛选条件均匹配。

| 场景 | 操作与预期 |
|---|---|
| 时间边界 | 有权记录 A 此刻生效、B 此刻失效、C 已生效且无失效时间、D 明日生效。开启后只显示 A、C。 |
| 组合与翻页 | 在第 3 页设置关键词再开启：回第 1 页，只显示同时满足关键词和有效时间的有权记录，页大小不变。关闭后只移除时间条件。 |
| 空结果与失败 | 无有效记录时显示空状态；模拟查询失败时保留开关及输入。重试成功后用这次查询结果替换错误提示。 |
| 越权反例 | A、C 中 C 超出员工数据权限时只显示 A；无入口权限者直接访问或构造请求也被拒绝。 |

本例没有未决业务选择。后续若要保存偏好、跨端同步或修改制度状态，作为新变更评估，不能顺带实现。
