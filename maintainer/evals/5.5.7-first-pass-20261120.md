# 5.5.7 首次作答与迁移题记录

2026-11-20 在两个独立模型（GPT-6.2 Astra、GPT-6.2 Sol）上，分别比较纯模型与安装版 5.5.7。四组使用相同题目、HTML、工具权限和 high 推理设置，分别冻结首次答案。判据在作答前确定。安装样本来自 11 月 18 日的本地候选。

| 题目 | 观察和判定 |
| --- | --- |
| 交班时选择一张看板，接班人打开同一交班单 | 四组均实际操作了非默认选项。交出时显示所选看板，接班时显示默认看板。四组均判定这条路径未通过。 |
| 给退料单增加存放架号，保留旧单 | 四组均保留旧记录，把扫码和自动分配留在本期范围外。两份 Sol 答案均为新记录直接指定可空。两份 Astra 答案中，一份把新记录空值列为待定，另一份只说明新记录有值和旧记录无值的路径。 |
| 修改规格参考后的新题：温室取样记录新增标签颜色 | 同题再做四个独立首答。纯 Astra 和纯 Sol 都指定新记录颜色可留空。两份带修订版 Skill 的首答都保留新记录的待决分支，同时交付颜色的录入、保存、回读和旧记录兼容。 |

修订只进入规格参考。原对象允许缺值，可以决定历史兼容；新建记录的输入限制仍需要相应业务决定。保持主入口和普通需求的交付负担。

两题组内每种条件各一次首答。迁移题另行补跑了同输入的纯模型对照，但没有在同题运行修订前的 Skill。没有人类接收者盲评、成本或稳定性估计。这些观察能指导本次维护，不能分离单句修改的作用或估计模型排名、普遍增益。运行包的来源、工程验证和发布状态由本版标签和发行记录另行确认。
